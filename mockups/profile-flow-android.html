Data wired up

Self profile reads UserDto; public profile reads PublicPlayerProfileDto; achievements read GamificationDto; friends use FriendshipDto + has_played_with(); favorites use FavoriteDto with FavoriteEntityType for the venue/coach split.

Privacy contract

profile_visibility column on users with three values (public/friends/hidden). Public read-path for PublicPlayerProfileDto respects the column; hidden excludes the user from matchmaking suggestions entirely. Phone & email never serialized in the public DTO.
